# Project Documentation

This folder contains the durable plans and decisions for AppBuilder Hackathon.

## Folders

- `plans/` — product direction, implementation phases, demo scripts, and acceptance criteria.
- `decisions/` — architecture decision records explaining choices and tradeoffs.
- `todo/` — known follow-up refactors with their reason and acceptance criteria.
- `design/` — the Angat design system: brand, color, type, components, and motion rules every screen follows.

## Documentation Rules

- Plans describe what we intend to build and how we will prove it works.
- Decision records capture choices that would be expensive or confusing to rediscover.
- Mark open questions and assumptions clearly.
- Update documentation in the same change as the behavior or decision it describes.
- Do not store secrets, credentials, private user data, raw recordings, or runtime state here.
